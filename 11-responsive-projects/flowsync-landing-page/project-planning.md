# 📏 Spacing System

```
4px    → very small gaps
8px    → small gaps
12px   → small/medium
16px   → standard
20px   → medium
24px   → medium/large
32px   → section/component spacing
40px   → large
48px   → large
64px   → section spacing
```

---

# 📦 Border Radius

Small elements → 6px – 8px
Buttons → 8px – 10px
Cards → 12px – 16px
Large containers → 16px – 20px
Pills → 999px
Circular elements → 50%
